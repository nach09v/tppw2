# Trabajo Práctico React - Universidad UPATECO

Sitio web desarrollado con **React** que incluye:
- Formulario de contacto funcional con **EmailJS**.
- Mapa embebido con la ubicación de la **Universidad UPATECO** al lado del formulario.

## Cómo ejecutar localmente
```bash
npm install
npm run dev
```

## Cómo publicar en GitHub Pages
```bash
npm run deploy
```
